
# House Price Prediction using Machine Learning

## Algorithms Used

- Linear Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost
- KNN
- SVM

## Technologies Used

- Python
- Google Colab
- Streamlit
- Scikit-learn
- XGBoost

## Deployment

Deployed using Streamlit Cloud.
